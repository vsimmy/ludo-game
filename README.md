# Ludo Game
A board I used to play as a kid. Simple roll the dice and click to move. First to go around and end with their respective color wins. Looking to redesign the UI and UX to improve animation and game play.

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.
